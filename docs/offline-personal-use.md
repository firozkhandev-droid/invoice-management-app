# Offline Personal Use

This branch keeps the production MySQL schema untouched and generates a separate SQLite schema for personal offline use.

## First Setup

```bash
copy .env.offline.example .env.offline
npm install
npm run offline:setup
```

## Start Offline App

```bash
npm run offline:dev
```

Open `http://127.0.0.1:3000`.

Register a local user from the app. Your offline data is stored on this computer only.

## Data Locations

- SQLite database: `prisma/offline.db`
- Uploads and generated files: `offline-data/uploads`

Back up both locations together.

## Production Safety

- Production deployment still uses `prisma/schema.prisma` with MySQL.
- Offline commands use `prisma/schema.offline.prisma`, generated by `npm run offline:schema`.
- Do not use offline commands on Hostinger.
